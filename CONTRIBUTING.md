# Contributing to My Assistant

Thank you for your interest in contributing! This document provides guidelines and information for contributors.

## Ways to Contribute

- 🐛 Report bugs
- 💡 Suggest new features
- 📝 Improve documentation
- 🔧 Submit code improvements
- 🧪 Add tests
- 🌍 Add translations

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/my-assistant.git`
3. Create a branch: `git checkout -b feature/your-feature`
4. Make your changes
5. Test your changes
6. Commit: `git commit -m "Add your feature"`
7. Push: `git push origin feature/your-feature`
8. Open a Pull Request

## Development Guidelines

### Code Style
- Follow PEP 8
- Use type hints for all functions
- Write docstrings for public APIs
- Keep functions under 50 lines
- Use meaningful variable names

### Testing
- Write tests for new features
- Ensure all tests pass: `pytest tests/`
- Aim for high test coverage
- Test on Windows 10 and 11

### Documentation
- Update README.md for user-facing changes
- Add docstrings to new functions
- Update docs/ for significant features
- Include code examples where helpful

### Commit Messages
Use clear, descriptive commit messages:
- `feat: Add voice command for brightness control`
- `fix: Resolve crash when microphone not available`
- `docs: Update installation instructions`
- `test: Add tests for intent engine`
- `refactor: Simplify command dispatcher`

## Pull Request Process

1. Update documentation if needed
2. Add tests for new functionality
3. Ensure CI passes
4. Get review from maintainers
5. Squash commits if requested

## Bug Reports

When reporting bugs, include:
- Windows version
- Python version
- Steps to reproduce
- Expected behavior
- Actual behavior
- Log files (if applicable)
- Screenshots (if UI-related)

## Feature Requests

For new features:
- Check if it's already planned
- Explain the use case
- Suggest implementation approach
- Consider backwards compatibility

## Code of Conduct

- Be respectful and inclusive
- Focus on constructive feedback
- Help others learn and grow
- Follow the project's goals

## Questions?

Open a discussion on GitHub or email dev@myassistant.app

Thank you for contributing! 🎉
